# binary-parser

Generator and parser of dat files including a plan of 1-7 training days with 3 exercises.

# Download

git clone https://github.com/Parsifal23/binary-parser.git

#Требования 

Qt Creator 5 и выше

#Описание

Изначально задача парсинга бинарного файла была на работе. Дана структура его на словах, и надо было суметь спарсить, отредактировать и сохранить новый бинарник или в виде .csv файла.

Для личной истории хотел сохранить этот проект. Как работать с bitset и json.

Разумеется, мне надо было убрать всю рабочую информацию, но хотел оставить общий алгоритм обработки бинарника. Кое-что убрал и переделал в план тренировок с 3 упражнениями (подтягивания, отжимания, приседания) с выбором количества дней: от 1 до 7 включительно.

#Генератор бинарника

Чтобы прочесть бинарник определенной структуры в зависимости от количества дней, его нужно сначала создать.
За это отвечает проект DatGenerator в одноименной папке.
Он создает бинарник, а парсер TrainingViewer в одноименной папке считывает его.

В Linux при первом открытии проекта DatGenerator в Qt Creator откроется окно настроек проекта. Выбор компилятора и т.п. 
В выбранном компиляторе слева в "Сборка и запуск" во вкладке "Запустить" в центральной области разных настроек надо поставить галочку "Запускать в терминале".

После запуска в Qt Creator проекта DatGenerator: в консоли (Windows) или встроенном терминале Qt Creator (Linux) введите количество тренировочных дней от 1 до 7 включительно. И нажмите Enter (1 или более раз, чтобы консоль закрылась).
В папке проекта в папке с названием, начинающимся с "build" создастся файл TrainingWeek1.dat. Его и надо будет открыть в парсере TrainingViewer.

#Парсер

Парсер имеет графический интерфейс с возможностью выбора режима количества тренировочных дней по кнопке "Выбрать режим".
Выбирать надо то количество дней, какое вы указали в DatGenerator.
Затем по кнопке "Открыть файл" выберите бинарник TrainingWeek1.dat, созданный ранее.

Появится таблица с данными тренировок.
Первые 3 столбца указывают прогресс или регресс по указанным упражнениям с диапазоном возможных значений. Диапазон ограничен количеством битов, в которых хранится значение (помните, я говорил, что хотел сохранить алгоритм обработки бинарника?).
Следующий столбец указывает на относительную тяжесть тренировки по сравнению с прошлой.
Остальные столбцы показывают абсолютные значения в упражнениях на день тренировки.

Все значения можно редактировать через контекстное меню по правой кнопки мыши, щелкнув по ячейке.
И имеется возможность сохранить данные в csv файл или новый бинарник.
Сохраненный бинарник будет лежать в папке с исходными файлами проекта.

#Примечание

В Linux стиль оформления таблицы в TrainingViewer будет зависеть от системной темы.
